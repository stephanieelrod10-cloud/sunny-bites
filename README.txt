SUNNY BITES PWA FILES
These files prepare Sunny Bites to be hosted as an installable Progressive Web App (PWA).

FILES
- index.html: game
- manifest.webmanifest: app name, icon, and install settings
- sw.js: offline caching
- icons/: app icons

PHONE-ONLY NEXT STEPS (FREE HOSTING OPTION)
1. Create/sign in to a GitHub account in your phone browser.
2. Create a new public repository named sunny-bites.
3. Upload all files/folders from this ZIP, keeping the folder structure.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to provide an HTTPS website address.
7. Open that address in Chrome on your Android phone. Use Chrome menu (⋮) > Install app or Add to Home screen.
8. Test offline mode and game saving.

GOOGLE PLAY LATER
PWABuilder can package a hosted PWA for Android, but Google Play publication requires a Play Console developer account (currently a one-time US$25 fee), identity verification, and applicable testing requirements. A hosted PWA is not automatically published to Google Play.
